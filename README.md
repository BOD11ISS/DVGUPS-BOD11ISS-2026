## 🫣 Перед отправкой необходимо скачать Git и настроить папку для ДЗ у вас на компьютере

### **1.** Установка Git
Официальная страница установки Git:

  ↳  https://git-scm.com/install/windows *(Не только 🪟 Windows, есть установщик на 🍎 macOS и 🐧 Linux)*

Следуйте инструкциям на официальном сайте, после установки можете переходить к отправке домашки.

> *Если возникли проблемы с установкой Git обратитесь в __❓ Помощь__ по контактам выше...*

### **2.** Настройка папки
**2.1** Создайте папку для ДЗ в удобном для вас месте

**2.2** Открываем cmd в пути папки домашки.
🪟 Windows | 🍎 macOS | 🐧 Linux
---|---|---
В папке с домашкой нажимаем на путь к папке *(Он должен выделится)*, после чего вводим туда `cmd`, нажимаем Enter. | Открываем Терминал, пишем `cd `*(обязательно с пробелом в конце)*, переносим в окно Терминала папку с домашкой, нажимаем Enter.| ХЗ
*Гиф* | *Гиф* | *Гиф*

**2.3** В командную строку пишем `git init` и Нажимаем Enter. Это создаст внутри папки с дз, скрытую папку .git, что позволит работать с файлами в вашей папке.

**2.3** В командную строку пишем `git remote add VKP-HW <ССЫЛКА_НА_ВАШ_РЕПОЗИТОРИЙ>` и Нажимаем Enter. Это создаст внутри папки с дз, скрытую папку .git, что позволит работать с файлами в вашей папке.

## 🥹 Как отправить домашку на проверку?

**1.** Проверьте чтобы в папке с домашкой была только домашка, ничего другого!

**2.** Открываем cmd в пути папки домашки.
🪟 Windows | 🍎 macOS | 🐧 Linux
---|---|---
В папке с домашкой нажимаем на путь к папке *(Он должен выделится)*, после чего вводим туда `cmd`, нажимаем Enter. | Открываем Терминал, пишем `cd `*(обязательно с пробелом в конце)*, переносим в окно Терминала папку с домашкой, нажимаем Enter.| ХЗ
*Гиф* | *Гиф* | *Гиф*

**3.** В командную строку пишем `git add .` и Нажимаем Enter. Это выберет все файлы в папке.

**4.** В командную строку пишем `git commit -m "Домашнее задание <Здесь пишем сегодняшнюю дату>"` и Нажимаем Enter. Это сохранит состояние выбранных ранее файлов.

**5.** В командную строку пишем `git push VKP-HW master` и Нажимаем Enter. Это отправит все сохранённые файлы на GitHub.
